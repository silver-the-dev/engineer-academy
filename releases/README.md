- **Instalação:** baixe o APK no celular, abra o arquivo e permita "instalar apps desconhecidos" para o navegador ou gerenciador de arquivos quando o Android pedir.
- **Atualização:** todas as versões têm a mesma assinatura (certificado SHA-256 `fac61745…033b9c`), então uma versão nova instala por cima da anterior e mantém o progresso.

Para conferir a integridade de um download: `sha256sum EngineerAcademy-v<versão>.apk`.
